# 💱 CurrencyBot

Telegram-бот для конвертации валют на Python с использованием aiogram.

## Возможности

- 💱 Конвертация валют
- 📈 Актуальные курсы валют
- 📜 История операций
- ℹ️ Помощь

## Технологии

- Python 3.11
- aiogram 3
- SQLite
- SQLAlchemy
- Requests

## Запуск проекта

1. Клонировать репозиторий

```bash
git clone https://github.com/Khushnudik/CurrencyBot.git
```

2. Установить зависимости

```bash
pip install -r requirements.txt
```

3. Создать файл `.env`

```text
BOT_TOKEN=ВАШ_ТОКЕН
```

4. Запустить

```bash
python main.py
```
